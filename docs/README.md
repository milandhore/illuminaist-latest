# IlluminAIst project documentation

This directory is the source of truth for product intent, architecture,
operations, security, and delivery. The site is a Vite/React static web app
with HashRouter-compatible GitHub Pages deployment and an optional local CMS.

See the numbered documents in this directory for the product, design,
architecture, data, API, agent, setup, implementation, security, integration,
testing, and debugging guidance.

Sensitive data does not belong in this directory or in `public/`.
