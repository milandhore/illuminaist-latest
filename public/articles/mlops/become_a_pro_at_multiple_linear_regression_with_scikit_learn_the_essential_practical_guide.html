Splitting the Data

Train/Test Split is a crucial technique in machine learning that involves dividing the dataset into two distinct subsets: a training set and a testing set. These sets are mutually exclusive, meaning no data point appears in both sets simultaneously.

  • The model is then trained using the training set and evaluated using the testing set. This approach provides a more accurate assessment of the model’s out-of-sample performance, as the testing data has not been used during the training process.
  • Consequently, this method offers valuable insights into how well the model generalizes to new, unseen data. The testing dataset is particularly valuable because we know the true outcomes for each data point within it. Since this data has been kept separate from the training process, the model has no prior knowledge of these outcomes.
  • This makes the testing phase a genuine out-of-sample evaluation, closely mimicking real-world scenarios where the model encounters completely new data.
  • To implement the Train/Test Split, we’ll divide our dataset into two portions. Typically, about 80% of the entire dataset is allocated for training, while the remaining 20% is reserved for testing.
  • To achieve this split, we’ll create a mask that randomly selects rows from the dataset. This can be accomplished using the np.random.rand() function, which generates random numbers that we’ll use to determine which data points belong to each set.We split the dataset into training and testing sets to evaluate our model’s performance:

Multiple Regression Model

In practice, numerous factors influence CO2 emissions. When analyzing scenarios with more than one independent variable, we employ a technique known as multiple linear regression.
A practical application of this method is forecasting CO2 emissions by considering various car characteristics such as combined fuel consumption, engine size, and the number of cylinders. It’s worth noting that multiple linear regression is essentially an expanded version of the simple linear regression model, allowing for a more comprehensive analysis of complex relationships between variables.

In this example of multiple linear regression we are predicting co2emission using the features like FUELCONSUMPTION_COMB, EngineSize and Cylinders of cars. Multiple linear regression model is the extension of the simple linear regression model where we use one independent variable/feature to predict dependent variable.

Technical Deep Dive

Ordinary Least Squares (OLS)

The multiple linear regression model is built using the Ordinary Least Squares (OLS) method. OLS is a method for estimating the unknown parameters in a linear regression model. It minimizes the sum of the squares of the differences between the observed dependent variable and those predicted by the linear function.

Mathematical Formulation

The multiple linear regression equation can be expressed as:

Y=β0+β1X1+β2X2+...+βnXn+ε

Where:

Y is the dependent variable (CO2 emissions in our case).
𝛽0 is the intercept.
𝛽1,𝛽2,...𝛽𝑛 are the coefficients for the independent variables.
𝑋1,𝑋2,…,𝑋𝑛 are the independent variables (engine size, cylinders, fuel consumption).
𝜖 is the error term.

Model Evaluation Metrics

To evaluate the performance of our regression model, we use the following metrics:

  • Mean Squared Error (MSE) : Measures the average of the squares of the errors, i.e., the average squared difference between the estimated values and the actual value.
  • Variance Score : Also known as the coefficient of determination (R2R2), it indicates how well the independent variables explain the variability of the dependent variable. A score of 1 indicates perfect prediction, while a score closer to 0 indicates poor prediction.
