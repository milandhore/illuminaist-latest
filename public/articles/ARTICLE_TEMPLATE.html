Section Two — Code Examples

Paste code examples inside pre + code blocks. They render with a dark terminal background and a monospace font. 

// JavaScript / TypeScript example
import { ChatOpenAI } from '@langchain/openai'

const llm = new ChatOpenAI({ model: 'gpt-4o', temperature: 0 })
const response = await llm.invoke('Explain RAG in one sentence.')
console.log(response.content)

# Python example
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o", temperature=0)
response = llm.invoke("Explain RAG in one sentence.")
print(response.content)

Use inline code tags for file names, class names, or short values like temperature=0 mentioned in a sentence.
