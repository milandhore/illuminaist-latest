Introduction

Retrieval-Augmented Generation (RAG) has emerged as the dominant pattern for grounding LLMs in proprietary data. But most tutorials stop at "embed your docs, query the vector DB." Production RAG is a different beast entirely.

In this guide we walk through an enterprise-grade RAG pipeline using LangChain v0.3 and Pinecone Serverless — from document ingestion to latency-optimised retrieval.

1. Chunking Strategy Matters More Than You Think

Naive fixed-size chunking (512 tokens, 10% overlap) is a common starting point but rarely optimal. For technical documentation, recursive character text splitting with semantic boundary awareness outperforms fixed chunking by 18–23% on recall@5 benchmarks.

from langchain.text_splitter import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1024,
    chunk_overlap=128,
    separators=["\n\n", "\n", ". ", " ", ""]
)
chunks = splitter.split_documents(docs)

2. Choosing Your Embedding Model

The embedding model is the single biggest lever on retrieval quality. As of Q3 2026, text-embedding-3-large from OpenAI and embed-english-v3.0 from Cohere lead on MTEB benchmarks for English retrieval tasks.

Cost vs. Quality Trade-off

For high-volume systems, consider two-stage retrieval: use a cheap bi-encoder (e.g., all-MiniLM-L6-v2) to fetch top-100, then re-rank with a cross-encoder (e.g., Cohere Rerank 3) to produce top-5.

3. Pinecone Serverless Setup

import pinecone
from pinecone import Pinecone, ServerlessSpec

pc = Pinecone(api_key=os.environ["PINECONE_API_KEY"])
pc.create_index(
    name="illuminaist-rag",
    dimension=3072,  # text-embedding-3-large
    metric="cosine",
    spec=ServerlessSpec(cloud="aws", region="us-east-1")
)

4. Re-ranking for Precision

After initial retrieval, apply a cross-encoder re-ranker to improve precision. This two-step approach consistently outperforms single-stage dense retrieval.

In our benchmarks, adding Cohere Rerank 3 to a Pinecone pipeline improved answer faithfulness by 31% and reduced hallucination rate by 44%.

5. Evaluating Your Pipeline

Use RAGAS for automated evaluation. Key metrics: Context Recall, Context Precision, Answer Faithfulness, and Answer Relevancy.

from ragas import evaluate
from ragas.metrics import (
    answer_faithfulness,
    answer_relevancy,
    context_recall,
    context_precision,
)

result = evaluate(
    dataset,
    metrics=[answer_faithfulness, answer_relevancy, context_recall, context_precision],
)
