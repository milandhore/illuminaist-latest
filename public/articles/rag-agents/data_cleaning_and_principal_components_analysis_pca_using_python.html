G ood data hygiene is very important for business. At high level, Data cleaning (sometimes also known as data cleansing or data wrangling) is an important early step in the data analytics process. E1: Principal Components Analysis (PCA)

PCA is used to reduce dimensionality of datasets. It also helps to address model overfitting problems. PCA only works with numeric values/variables.

Basic Steps to perform PCA

· Data Normalization for standardization

· Computing Covariance Matrix

· Calculating Eigenvector and eigenvalue

· Compute Principal Components

· Reduce data dimension

Refer section E1 and above principal component analysis(pca) code snippet

· For PCA work I have imported sklearn decomposition libraries. Sklearn.decomposition.pca has simplifies the PCA work using linear dimensionality reduction method. I have used PCA() function from sklearn

· At first, I have normalized the data to get all features at one scale. Normalizing data is important otherwise biggest dispersion column dominate loading to components.

· I have used “Sree” plot visualization to understand which features help to preserve original dataset variance after dimension reduction

· To understand how each component associated with other component, I have calculated eigenvalues and eigen vectors

· Kaiser criterion approach (Eigenvalues ≥1) I have used Sree plot with Kaiser criterion approach to identity all Principal component for loadings. We can see that 20 component help to preserve 98% of variance.

· To understand variance ratio in percentage form, I have also used pca.explained_variance_ratio_

· To calculate total variance preserve by all selected component, I have used np.cumsum() function

· To understand which variables are most significant in explaining the original datasets total variance, I have calculated loadings for each component. This helped to understand highest loadings in components.

E3: Benefits of PCA

· We have 50 features in original dataset but based on PCA, we can say that 20 components explain approximately 98% of the variance which means these 20 features can play significant role for EDA and model training. Reducing dimensionality of dataset and removing correlated features from original dataset improve algorithm training and save cost on model training.

· During PCA work, we have used “Sree plot” which easily help us to visualize eigen values ≥ 1 & identify which components are significant for selection without impacting original dataset variance.

· With PCA, we have not only reduced number of features but also found important features required for decision making based on given dataset. Such as company should more focus on customer services and timely response as per survey data features.

· Model training with limited as well as significant features reduces model overfitting challenges.

· With the help of PCA & correlation matrix, we can say that increasing monthly charges for service can impact customer churn rate.
