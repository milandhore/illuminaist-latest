T he goal of this article is to demonstrate how to achieve automated and autonomous publishing of integration architecture documentation. In this solution, users simply upload architecture diagrams (PDFs or images), and the rest of the process — text extraction, conversion, storage, and contextual analysis — is handled seamlessly by an Agentic AI-powered workflow.

To implement this solution, I have containerized the n8n platform locally using Docker. This setup enables efficient development and deployment of workflows while leveraging the capabilities of Google Cloud’s Vertex AI and Gemini Chat Model for text extraction and analysis.

Introduction to n8n

n8n is a powerful open-source workflow automation tool that enables users to create custom workflows without extensive coding knowledge. It provides a visual interface where users can connect different nodes, representing actions or triggers, to automate tasks across apps and systems. With over 1,250 pre-built templates and integrations for platforms like Google Vertex AI, AWS, and more, n8n is a versatile solution for businesses seeking efficient automation.

Docker Integration: Building the Framework

To deploy n8n effectively, Docker was utilized to create a containerized environment. This approach ensures scalability, portability, and ease of management. Here’s how the framework was built:

Installing Docker and Docker-Compose :

  • Docker was installed on a Linux-based server following standard installation guidelines.
  • Docker-Compose was configured to manage multi-container applications seamlessly.

Creating the Docker Environment :

  • A docker-compose.yml file was created to define services like n8n and Traefik (for reverse proxy).
  • An .env file was set up to manage environment variables securely.

Launching the Container :

  • The docker-compose up command initialized the n8n instance.
  • Authentication and HTTPS were configured for secure access

This setup allowed n8n to run in an isolated container, simplifying deployment and ensuring consistent performance across environments.

Core Features of n8n

n8n stands out due to its flexibility and extensive capabilities:

  • Visual Workflow Builder : A drag-and-drop interface lets users design workflows intuitively without writing code
  • Nodes for Actions and Triggers : Nodes represent specific tasks like sending HTTP requests, storing data in databases, or interacting with APIs

Use Case: Integration Architecture Analysis using Agentic AI router design

Scenario Overview

The use case involved analyzing an integration architecture diagram provided as an image or PDF. Using n8n’s workflow automation capabilities combined with Google Vertex AI, the diagram was interpreted and explained.

Workflow Steps

Understanding the Attached Workflow

The provided n8n workflow automates the process of extracting text from uploaded PDF or image files using Google Cloud’s Vertex AI and then storing the output in Google Drive. Here’s a detailed breakdown of the workflow:

1. Input: Uploading Files

  • Trigger Node: “Upload Architecture Pattern” The process begins when a user uploads a file (either a PDF or an image) to a designated folder in Google Drive. This node monitors the folder for updates (e.g., new files uploaded) and triggers the workflow.

2. Routing Based on File Type

  • Router Node: “Router Based Agent” This node evaluates whether the uploaded file is a PDF or an image. Based on the file type, it routes the workflow to the appropriate path for further processing.

3. Processing PDFs

For PDF files:

Download Node: “Download PDF” Downloads the PDF file from Google Drive.
Vertex AI Node: “Vertex AI Extract” Sends the PDF to Google’s Vertex AI for text extraction. Vertex AI uses machine learning to analyze and extract text from documents.
Convert Node: “Convert to Text File” Converts the extracted data into a plain text file format.
Upload Node: “Upload to Google Drive” Saves the processed text file back into Google Drive for easy access

4. Processing Images

For image files:

Download Node: “Download Image” Downloads the image file from Google Drive.
Vertex AI Node: “Vertex AI Extract Text” Processes the image using Vertex AI’s OCR (Optical Character Recognition) capabilities to extract text.
Convert Node: “Convert to Text File” Converts extracted text into a plain text file.
Upload Node: “Upload to Google Drive” Uploads the processed text file back into Google Drive.

5. Integration with Google Gemini Chat Model

In both paths (PDF and image), there is an optional integration with Google Gemini Chat Model, which could be used for further analysis, summarization, or contextual understanding of the extracted text.
