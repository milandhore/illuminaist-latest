Epic previews a game launcher described as vibe coded

Epic Games says its redesigned launcher was built with AI-assisted development, including faster performance and Linux support.

Epic Games has previewed a redesigned PC launcher and described parts of its development process as vibe coding. The update focuses on performance, design, and Linux support while showcasing AI-assisted software development.

The story reflects a broader shift in engineering workflows, where generated code can accelerate delivery but still needs testing, review, and long-term maintenance.
