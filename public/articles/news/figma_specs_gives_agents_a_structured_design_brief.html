Figma Specs gives agents a structured design brief

Figma’s Markdown-based Specs editor lets teams record design decisions that coding agents can read through MCP and related integrations.

Figma has introduced Specs, a Markdown-based editor for documenting design language and decisions that AI agents can read through MCP. The company is also expanding code-layer features that let agents generate and edit code from designs.

Structured context can reduce the gap between a design file and the intent behind it, giving coding agents clearer constraints than screenshots alone.
