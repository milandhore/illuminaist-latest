Meta opens Muse Spark Open for agentic coding

Meta has released an open-weight multimodal model with a one-million-token context window for codebases, debugging, and tool use.

Meta has unveiled Muse Spark Open, an open-weight mixture-of-experts model with multimodal text, image, audio, and video support. The model offers a one-million-token context window and targets agentic coding tasks such as reading codebases, debugging, and tool use.

The release adds pressure to hosted model providers by giving developers a large, customizable option that can fit into local and private infrastructure.
