FLUX.3 Image Klein adds fast open image generation

Black Forest Labs’ new open model supports text-to-image, reference images, layout boxes, quantization, and fast H100 inference.

Black Forest Labs has released FLUX.3 Image Klein with text-to-image, multi-reference image-to-image, and bounding-box layout control. The model includes quantized variants and LoRA tooling, with a distilled checkpoint designed for fast generation.

The release expands the options for teams that want to run image generation in their own stack and control fine-tuning, latency, and data handling.
