Reflection releases Beam, a 501B open model

Beam is an Apache 2.0 mixture-of-experts model with a one-million-token context window and tooling for coding and agentic workloads.

Reflection has released Beam, a 501-billion-parameter mixture-of-experts language model under the Apache 2.0 license. It offers a one-million-token context window, 23 billion active parameters per token, and day-one support across popular inference stacks.

The release adds another large open model for teams that want to customize coding and agent workflows without relying exclusively on a hosted API.
