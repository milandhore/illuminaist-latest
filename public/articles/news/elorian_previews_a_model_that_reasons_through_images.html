Elorian previews a model that reasons through images

Startup Elorian’s Glimpse model can crop, zoom, and run code during visual reasoning instead of processing an image only once.

Elorian has previewed Glimpse, a multimodal model that can iteratively inspect visual inputs by cropping, zooming, and running code during a reasoning process. The company says the research model is smaller and cheaper to train than leading alternatives.

If the approach holds up in independent testing, iterative visual inspection could make models more useful for robotics, video analysis, and other tasks where one-pass image understanding is not enough.
