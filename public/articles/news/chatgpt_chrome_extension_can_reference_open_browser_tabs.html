ChatGPT Chrome extension can reference open browser tabs

OpenAI’s updated Chrome extension can compare content across open tabs, making the assistant more context-aware for research and shopping.

OpenAI has updated its ChatGPT Chrome extension so it can access open browser tabs when the user asks. The feature is intended to compare pages and provide answers grounded in the user’s active research context.

Browser access is useful, but it also makes permission prompts, tab boundaries, sensitive-page detection, and clear user controls essential.
